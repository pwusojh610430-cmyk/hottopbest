# HotTopBest

An early-stage homepage concept for an AI + SEO growth toolkit. The visual direction is editorial, confident, and tool-first, with an original brand system inspired by modern SEO publications.

## Included in this prototype

- Responsive marketing homepage
- Interactive tool category filters and search
- SEO checker preview form
- AI and SEO tool cards
- Three-step product workflow
- Learning center and newsletter sections
- Mobile navigation

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```
